# 🎬 Amazon Prime Content Analytics Dashboard

## 📌 Project Overview
This project analyzes Amazon Prime Movies and TV Shows to identify content trends, popular genres, ratings, countries, release years, and movie durations. Data cleaning and analysis were performed using Python and SQL, and an interactive dashboard was created in Power BI to present meaningful insights.

## 🎯 Objectives
- Analyze Movies vs TV Shows distribution.
- Identify content trends across release years.
- Analyze top contributing countries and genres.
- Study content ratings and movie durations.
- Build an interactive Power BI dashboard for data-driven insights.

## 📈 Key Insights
- Movies make up the majority of the content available on Amazon Prime.
- Content additions have increased significantly in recent years.
- The United States is among the leading content-contributing countries.
- Drama and other entertainment-focused genres have a strong presence.
- Movie durations are concentrated around typical feature-film lengths.
- The platform offers content across a wide range of ratings.
